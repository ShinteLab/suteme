外部（ikkyoku など）から訓練データを登録するための口です。 登録された局面は履歴に 未確認 として入り、 解析タブで一度内容を確認して保存し直すまで学習には使われません。
オフの間は /api/status が enabled: false を返し、登録は 503 で断ります。
オフなら 127.0.0.1 からのみ。オンにしても外から触れるのは /api/status と /api/register だけで、 学習・削除・セッション系は常にローカル限定です。
ローカルからのアクセスには要求しません（この画面が動かなくなるため）。
登録リクエストの形式 
POST /api/register   multipart/form-data
  image        画像ファイル（PNG / JPEG）
  sfen         正解の SFEN（盤面部分だけでも可）
  x1,y1,x2,y2  盤面の外枠座標（必須）

Authorization: Bearer <token>   ※トークンを要求する設定のとき

200  {"status":"ok","id":"...","verified":false,"entries":12}
200  {"status":"ok","id":"...","duplicate":true}   同じ画像の再送
400  座標が無い / 画像が壊れている
401  トークンが不正
503  API 登録が無効
507  履歴が上限（古い局面は消しません）
学習するだけならチェックを付けて「選択した局面で学習」。行をクリックすると解析タブで再入力できます。
